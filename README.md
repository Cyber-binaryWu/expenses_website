# Expense Management Website

This website allows users to **add, retrieve, edit, and delete expense data** while keeping the data persistent using **SQLite**, a lightweight database that is built into Python.

The application provides a **graphical user interface (GUI)** that makes it easy for users to view and manage their expenses in a simple and understandable way.

## What I Learned

Through this project, I learned:

* How to design a database in a way that avoids unnecessary complexity and makes it easier to add new features in the future.
* How to use **Flask** to build a responsive web application.
* General debugging techniques and how to investigate problems when something doesn't work as expected.
* How to interact with HTML elements to delete data and provide users with instant feedback.
* How to set up a project using **uv** and virtual environments to keep the development environment consistent.
* How to use **Git commands** to manage and track a project.
* The importance of providing users with fast and clear feedback when they interact with an application.

## Future Improvements & Learning

There are several areas I would like to improve as I continue developing:

* **Consistent naming:** I became more consistent with naming throughout the project, but I would like to improve this further and maintain consistent naming conventions from the beginning.
* **Explore alternative approaches:** Try different ways of implementing features rather than always using the first approach that works. This will help me understand different techniques and improve my problem-solving skills.
* **Learn more about APIs:** Most of the interactions in this project use form requests. In future projects, I would like to make more API requests from the JavaScript side. This would allow me to learn more about APIs, JavaScript, and how front-end and back-end systems communicate.
